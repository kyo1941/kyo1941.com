# 記事の書き方

ブログとポートフォリオの本文の書き方です。
同じ本文をそのまま Zenn にも載せられるよう、サイト独自の記法は作らず、Zenn と同じ書き方に揃えます。

## アコーディオン

`:::details タイトル` の行から `:::` の行までが、タイトルを押すと開くアコーディオンになります。

```
:::details タイトル
中身
:::
```

入れ子にするときは、外側のコロンを増やします。
閉じる行は開いた行と同じ数以上のコロンで判定するため、内側と同じ数にすると内側の `:::` で外側も閉じてしまいます。

```
::::details 外側
:::details 内側
中身
:::
::::
```

コードブロックの中に書いた `:::details` と `:::` は、アコーディオンにならずにそのまま表示されます。

## 引用

`> ` で始まる行は引用になります。

## 図

` ```mermaid ` のコードブロックは、Mermaid の図として描画されます。

## HTML

`frontend/src/app/utils/remarkArticleHtml.ts` の許可リストにある小文字のタグだけを HTML として扱います。
それ以外のタグの形をした文字列（`Flow<T>` など）は、文字としてそのまま表示されます。
使えるタグを増やすときは、この許可リストに足します。
